# 星塵幻獸 Stardust Beasts

一款**原創**的等角（Isometric）回合制幻獸 RPG 網頁遊戲。

- 純前端、免後端：用 **Vite + TypeScript** 開發，所有美術皆以 Canvas **程式化即時繪製**，音樂與音效則以 **Web Audio API 即時合成**（完全沒有任何外部圖片、音訊或字型檔）。
- 世界觀、劇情、角色、幻獸、地圖、技能與數值全部原創，非任何既有作品的複製或移植。

> 本專案是「同類型玩法」的原創作品：8 方向格子移動、等角瓷磚地圖、回合制幻獸戰鬥、封印（捕捉）系統、屬性相剋、商店與存檔。

## 🎮 線上遊玩

**https://theliberalartspressad.github.io/webgame/**

免安裝、免登入，用瀏覽器打開即可遊玩。建議使用電腦鍵盤（方向鍵 / WASD）。

## 快速開始

### 需求
- Node.js 18 以上（開發時使用 v24）
- 現代瀏覽器（Chrome / Edge / Firefox / Safari）

### 安裝與啟動
```bash
cd stardust-beasts
npm install
npm run dev
```
終端機會印出網址（預設 `http://localhost:5173/`），用瀏覽器打開即可遊玩。

### 管理後台
```bash
npm run dev
# 遊戲：   http://localhost:5173/
# 後台：   http://localhost:5173/admin.html
```
或直接執行 `npm run admin`（會自動開啟後台）。

後台可以調整：

| 分類 | 可修改內容 |
| --- | --- |
| 幻獸 / 人物 | 名稱、屬性、外觀、Lv1 基礎能力、每級成長、捕獲率、圖鑑說明、技能學習表、進化、**被動特性** |
| 技能 | 威力、MP、屬性、類型、目標、物理/魔法、增益減益、異常狀態機率與回合 |
| 道具 | 售價、使用場合、回復量、固定傷害、封印、逃脫、傳送、**傳授技能、裝備（欄位／加成／抗性）** 等效果 |
| 商店 | 上架道具、收購價倍率、即時買賣價預覽 |
| 遇敵 | 每張地圖的遇敵率、出現種族、等級範圍、權重與出現機率 |
| 劇情戰鬥 | 敵人組合、等級、BOSS / 可逃跑、背景、開場文字、勝利後動作、**頭目階段（狂暴 / 增援 / 回復）** |
| 公式規則 | 升級經驗、戰鬥經驗、金幣、傷害、爆擊、治療、捕獲、逃跑、中毒、**流血**、**混亂**、收購價 |
| 存檔 / 角色 | 直接修改等級、能力、HP/MP、技能、道具數量、金幣、地圖位置、劇情旗標、圖鑑 |
| 匯出 / 匯入 | 將整份設定下載成 JSON，或從其他瀏覽器匯入 |

> 設定與存檔都保存在瀏覽器 `localStorage`，管理頁和遊戲必須使用**同一個網址（含 port）**。修改後請按後台的「儲存設定」，再重新整理遊戲分頁。

### 打包正式版
```bash
npm run build      # 產出 dist/（含型別檢查）
npm run preview    # 以本機伺服器預覽打包結果
```

> ⚠️ 請用 `npm run dev` 或 `npm run preview` 開啟。直接雙擊 `dist/index.html`（`file://`）會因為瀏覽器對 ES Module 的 CORS 限制而無法載入。

## 操作說明

### 探索
| 按鍵 | 功能 |
| --- | --- |
| 方向鍵 / WASD | 在等角地圖上移動（單鍵 = 斜向；兩鍵同按 = 純 X / 純 Y 軸方向） |
| 空白鍵 / Enter | 與前方或身邊的人、告示牌交談；在**委託板**前開啟委託清單 |
| Esc / X | 開啟主選單（隊伍 / 道具 / 裝備 / 合成 / 圖鑑 / 成就 / 系統） |

### 主選單
| 按鍵 | 功能 |
| --- | --- |
| Q / E 或 Tab | 切換頁籤（隊伍 / 道具 / 裝備 / 合成 / 圖鑑 / 成就 / 系統） |
| ↑↓ | 選擇 |
| ←→ | 在「裝備」頁籤切換武器 / 防具 / 飾品欄位 |
| 空白鍵 / Enter | 確定（穿戴、卸下、使用、領取圖鑑獎勵、切換音效、開啟子選單） |
| V | 在「隊伍」頁籤選擇**進化分支** |
| F / G | 在「裝備」頁籤切換**工房**模式：F＝強化、G＝鑲嵌（再按一次關閉） |
| X | 在「裝備」的鑲嵌模式取下最後一顆寶石；在「合成」頁籤清除已選的幻獸 |
| Esc | 關閉 |

### 合成頁籤
| 按鍵 | 功能 |
| --- | --- |
| ↑↓ | 選擇幻獸 |
| 空白鍵 | 依序設定 A、B（再按一次可重新選擇） |
| Enter | 執行合成（消耗金幣與兩隻幻獸） |
| X | 清除 A / B |

### 委託板
| 按鍵 | 功能 |
| --- | --- |
| 空白鍵 / Enter | 接取 / 回報委託 |
| X | 放棄進行中的委託 |
| R | 更換一批**隨機委託** |

### 戰鬥
| 按鍵 | 功能 |
| --- | --- |
| ↑↓←→ / WASD | 選擇指令與目標 |
| 空白鍵 / Enter | 確定 |
| Esc | 返回上一層；在主指令時再按一次可開啟戰鬥說明 |

指令：**攻擊 / 技能 / 道具 / 封印 / 防禦 / 逃走**
- **封印**：消耗「封印石」，敵方 HP 越低成功率越高（BOSS 無法封印）。
- **防禦**：該成員本回合受到的傷害減半。
- **逃走**：劇情 BOSS 戰無法逃走。

## 遊戲系統

- **屬性相剋**：火 → 風 → 地 → 水 → 火
  - 效果絕佳 ×1.6、效果不佳 ×0.6（無屬性不受影響）。
- **場地效果**：每張戰鬥背景都有自己的屬性加成（草原／洞窟／古道／港口／雪原／火山／天空／深淵／星海／爐火），
  對應屬性傷害 ×1.2～×1.3，戰鬥畫面頂端會標示目前場地。
- **異常狀態（6 種）**：
  | 狀態 | 效果 |
  | --- | --- |
  | ☠ 中毒 | 每回合結束損失 6% 最大 HP |
  | ✚ 流血 | 每回合結束損失 8% 最大 HP（傷害更高） |
  | ⚡ 麻痺 | 每回合 50% 機率無法行動 |
  | Z 睡眠 | 必定無法行動，**受到傷害時驚醒** |
  | ❄ 冰凍 | 必定無法行動，**受到傷害時碎裂解除** |
  | ？ 混亂 | 35% 機率無法行動；可行動時有 50% 機率**攻擊自己** |
  - 由「毒牙」「麻痺掌」「搖籃曲」「霜華爆」「虛空爪」「血月」「冰縛」「混沌凝視」「深淵之握」等技能造成；
    可用**解毒草**或技能**淨化**／**大淨化**解除。
- **頭目階段機制**：劇情頭目在血量降到門檻時會**狂暴化**（全體增益）、**呼叫增援**或**回復自身**，
  戰鬥中會以訊息提示，後期頭目最多三段變化。
- **技能石**：可在道具欄對隊伍成員使用，直接教會指定技能（重複使用會返還道具）。
- **幻獸隊伍**：出戰最多 4 隻，其餘放在待命區；可在選單中自由編排。
- **升級與進化**：戰鬥勝利後全隊獲得經驗值，升級時自動學會新技能並補滿 HP / MP；
  部分幻獸達到指定等級會**進化成另一種族**（如 微風精 → 疾風鷹、雪犬 → 霜甲熊、火苗犬 → 炎狐）。
- **進化分支**：有些幻獸擁有多條進化路線，條件各不相同（**等級、道具、屬性、潛能、劇情旗標**）。
  符合條件時可在「隊伍」頁籤按 **V** 選擇要走上哪一條分支；沒有綁定道具的分支在升級時會自動判定。
  進化後的種族會登錄圖鑑。
- **隱藏種族（16 種）**：不在地圖上出現、也無法直接封印，只能透過**特定合成配方**、**育種**或**高等進化**取得；
  圖鑑中會以「★」標示。牠們擁有專屬的被動特性與技能。
- **圖鑑**：收服或加入過的幻獸會登錄到圖鑑，附編號（No.001～）、屬性、Lv1 基礎能力、技能學習表與進化條件。
- **圖鑑收集獎勵**：圖鑑登錄數達到門檻（**18 階：5 / 8 / 12 / 16 / 21 / 26 / 31 / 36 / 42 / 47 / 51 / 54 / 59 / 63 / 67 / 71 / 74 / 77 種**）時，
  可在圖鑑頁籤按**空白鍵**一次領取獎勵（金幣、道具、裝備與經驗值）。
- **裝備系統**：每隻幻獸可穿戴 **武器 / 防具 / 飾品** 各一件，裝備提供固定或百分比加成（攻擊、魔力、HP…）與異常狀態抗性；
  在選單的「裝備」頁籤選擇幻獸與欄位即可穿脫，換下來的裝備會自動回到背包。最終能力＝種族基礎值＋裝備加成。
- **裝備強化與鑲嵌**：在「裝備」頁籤按 **F** 進入工房強化，每件裝備最高 **+10**（加成隨等級放大，愈高階需要星核）；
  按 **G** 進入鑲嵌模式，每個欄位最多 **3 顆寶石**，按 **X** 可取下最後一顆。
  強化與鑲嵌的加成都會即時反映在能力值上。
- **寵物合成與育種**：「合成」頁籤可挑選兩隻幻獸（空白鍵依序選 A、B，Enter 執行），消耗金幣與雙親，
  產生新一代幻獸並得到**潛能**（0～50，每點提升全能力）與**世代**。
  特定組合有 24 種**固定配方**；沒有配方時依屬性決定結果，
  而**父母同屬性且合成後潛能達 30** 就能育出該屬性的**隱藏種族**。
- **成就系統**：「成就」頁籤共有 **40 項**成就（圖鑑、戰鬥、合成、強化、金幣、委託…），
  達成時會自動發放獎勵並在畫面下方提示。
- **每日委託**：每天（依本機日期）自動更新 **3 件**每日委託，完成後累計**連續全勤**天數；
  委託板上會以 `[每日]` 標籤區分。
- **種族被動特性（38 種）**：每個種族天生帶有一種被動，例如提升能力、屬性減傷、異常狀態免疫或抗性、
  吸血、連擊、逃跑必定成功、戰鬥後金幣 / 經驗加成等；被動與裝備的抗性、減傷會在戰鬥中自動生效。
- **道具**：回復（藥草 / 星泉之水 / 大藥草 / 星輝藥）、復活（鳳羽 / 不死鳥翎）、解毒草、星塵炸彈／高階炸彈／碎星彈（固定傷害）、傳送羽（回到最近造訪的城鎮）、封印石、乙醚（補 MP）、**萬靈解藥**、**星海秘藥**（全隊大回復）、**技能石**（傳授技能）、**各級武器 / 防具 / 飾品**、**強化素材（星塵核 / 星核）** 與 **12 種寶石**等。
- **商店**：晨曦村、暮色港、霜華港、風空港、星海渡口與碎星鍛坊的商人可購買與販售道具、裝備、寶石與強化素材（販售價為售價的 50%）。
- **委託板**：各城鎮都有**委託板**，可接下「討伐 / 封印 / 繳交 / 前往」等重複性或一次性委託；
  除固定委託外，每座城鎮還會提供 **3 件隨機委託**（依冒險進度產生不同難度與裝備報酬，按 **R** 可換一批）；
  進度會即時顯示在畫面左上角，完成後回報可換取金幣、道具或經驗值。
- **程序化音樂與音效**：以 Web Audio API 即時合成——標題、城鎮、商店、原野、戰鬥、頭目、深淵、星海、爐火、終曲與結局共 **11 首曲目**，
  每首都有**和弦進行（含七度和聲）、走路低音、琶音層與打擊樂（大鼓 / 小鼓 / 開合鈸）**；
  戰鬥與選單另有 **21 種音效**（含鍛造、鑲嵌、合成）；可在「系統」頁籤切換音效開關（設定會保存在瀏覽器）。
- **存檔（4 個欄位）**：標題畫面的「新的旅程 / 繼續冒險 / 刪除存檔」都會先選擇欄位（1～4），
  會顯示玩家名稱、等級、所在地、圖鑑數、金幣與遊玩時間；遊戲內「系統 → 存檔欄位」可切換要寫入的欄位，
  「儲存進度 / 重新載入存檔」作用於目前欄位。
- **全滅處理**：戰鬥失敗會自動全隊恢復並送回晨曦村，不會遺失進度。

## 章節攻略

### 第一章
1. 在**晨曦村**與星見長老交談，取得封印石。
2. 從村南石階前往**微風草原**，往草原深處走會遭遇暴走幻獸（劇情戰鬥）。
3. 戰鬥後與草原上的**遊俠少女**交談，鈴會加入隊伍。
4. 回村向長老報告，得知蝕影教團的消息。
5. 從草原北方進入**星塵洞窟**深處，挑戰晶石守衛（BOSS）。
6. 穿越**暮色古道**前往**暮色港**（途中會有教團的伏擊）。
7. 在港口碼頭與蝕影祭司 瓦倫 決戰。港口另有礦工老大**鐵山**可招募。

### 第二章：霜之國
8. 與暮色港的**船長 老莫**交談，搭船前往**霜華港**。
9. 向霜華**長老 伊莎**打聽消息（可恢復全隊），得知冰晶洞窟的守衛甦醒。
10. 經**霜牙雪原**（途中會遭狼群伏擊）北上進入**冰晶洞窟**，擊敗**冰晶巨像**。

### 第三章：流沙與火
11. 從霜牙雪原東側前往**流金沙原**（沙蟲與豺狼橫行）。
12. 往東進入**焰心地脈**，擊敗**熔岩魔王**。

### 第四章：星之盡頭
13. 從流金沙原北上抵達**風空港**，補給後登上**星穹神殿**。
14. 在神殿盡頭擊敗**星之霸主**，迎向結局。

## 終章：深淵迴廊（破關後）

看完結局後回到遊戲（或重新讀取存檔），風空港西側會出現一道裂縫，旁邊的**守望者 卡蘭**會說明情況。

15. 從風空港**西側**進入**深淵迴廊・入口**，擊敗門口的**深淵騎士**。
16. 穿過入口北上抵達**中樞**，擊敗**虛無獸**（會狂暴化、分裂出援軍並自我回復）。
17. 繼續北上抵達**最深處**，挑戰**深淵主宰**與牠的**虛空龍**（三段階段變化）。
18. 戰勝後迎向**真章結局**。

> 深淵迴廊的敵人等級為 31～46，並可在此收服**影犬／幽蛛／霜巫妖／深淵騎士／虛空龍／星靈**等新種族。
> 這裡也有專屬的委託（需先完成對應進度才會出現在委託板上）。

## 第五章：星海之願（真結局後）

看完**真章結局**之後，風空港東側的海面上會浮起一座渡口，旁邊的**守望者 卡蘭**會告訴你這件事。

19. 與卡蘭交談並搭上渡船，抵達**星海渡口**；渡守**星河**會給予補給並指路。
20. 往南進入**星霧林**，在林中遭遇星霧幻獸（劇情戰鬥）。
21. 往東穿越**彗星迴橋**，擊敗守在橋心的**彗星守衛**。
22. 再往東進入**碎星鍛坊**，擊敗爐火深處的**鍛爐魔像**（可在此購買星海裝備與寶石）。
23. 北上登上**星之搖籃**，挑戰**星海之主**與牠的稜彩幻龍、彗星之翼（三段階段變化）。
24. 戰勝後完成**星海之願**，並可著手培育**星海之主**、**新星巨龍**、**稜彩幻龍**等隱藏種族。

> 星海區域的敵人等級為 44～57，是遊戲中最高難度的區域。
> 星海幻獸（彗尾蜥、隕鐵牙獸、星靈梟）潛能達 15、等級達 40 後，可進化成**新星巨龍 / 荒根巨獸 / 彗星之翼**；
> 以特定組合合成則能取得**稜彩幻龍、星海鯨、烈陽鍛神、星霧女王**。
> 而潛能 45 的**極光精靈**在 Lv55 會進一步進化成**星海之主**。

## 委託板（支線委託）

四個城鎮與星海渡口都設有委託板，靠近後按**空白鍵 / Enter** 開啟。

| 類型 | 內容 |
| --- | --- |
| 討伐 | 擊倒指定幻獸一定數量 |
| 封印 | 成功封印（捕捉）指定幻獸 |
| 繳交 | 繳交指定道具（以目前持有量計算進度） |
| 前往 | 抵達指定地圖 |

除了 14 件固定委託，每座城鎮還會提供 **3 件隨機委託**（依冒險進度決定討伐目標、數量與裝備報酬）。
此外，每天會依本機日期自動更新 **3 件「每日委託」**（清單上以 `[每日]` 標示），完成當日全部每日委託可累積**連續全勤**天數。

- **空白鍵**：接取委託 / 回報已完成委託
- **X**：放棄進行中的委託（重複型委託可重新接取）
- **R**：更換一批隨機委託（會清除舊批次的進度）
- 進度會即時顯示在畫面左上角的「◆ 委託」面板；重複型委託可無限次數完成。

```

    battle.ts             傷害 / 捕獲 / 逃跑 / AI / 行動排序 / 異常狀態 / 場地加成 / 被動
    state.ts              遊戲狀態、多欄位存讀檔、升級、進化、合成、強化、鑲嵌、成就、圖鑑獎勵

  scenes/
    field.ts              探索場景（移動 / 對話 / 觸發 / 遇敵 / 背景音樂切換）
```

### 地圖描述方式
地圖以「字元網格字串」定義（例如 `T` 樹、`.` 草地、`X` 岩壁、`~` 水面），
載入時由 `buildGrid()` 自動補齊邊界與出入口，開發模式下會檢查 NPC / 傳送點 / 觸發點是否落在不可行走的格子上並於 Console 警告。

## 開發除錯介面

僅在開發模式（`npm run dev`）下會掛載 `window.__sb`：

| 指令 | 說明 |
| --- | --- |
| `__sb.goto('field', 11, 10)` | 傳送到指定地圖與座標 |
| `__sb.battle([['shadowwolf', 8]], 'field', false)` | 直接開始一場戰鬥 |
| `__sb.give('herb', 5)` | 取得道具 |
| `__sb.setLevel(12)` | 將全隊等級設為指定值 |
| `__sb.audio` | 音訊引擎（`play('hit')`、`setBgm('boss')`、`toggleMute()`） |
| `__sb.session.state` | 讀取目前遊戲狀態 |
| `__sb.scenes.top` | 目前最上層場景 |
